# Ticket Best Europe — новый дизайн (прототип)

**🔗 Открыть сайт: https://olegjak.github.io/ticketbest/**

Рабочий прототип нового фронтенда для https://ticketbest.eu на реальных данных с текущего сайта.
Без сборки и зависимостей: чистые HTML, CSS и JS.

## Запуск

```bash
python3 -m http.server 5173
```

Затем откройте http://localhost:5173

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Каркас: шапка (поиск, страна, язык), футер, cookie-баннер |
| `assets/styles.css` | Весь дизайн: токены цветов (только светлая тема), адаптив |
| `assets/app.js` | Роутинг, рендер страниц, фильтры, поиск, переводы (et / ru / en) |
| `assets/data.js` | Снимок данных с ticketbest.eu (события, туры, баннеры, описания) |
| `tools/scrape.py` | Сбор данных с текущего сайта |
| `tools/build_data.py` | Чистка данных и сборка `assets/data.js` |

### Страницы
- `#/` — главная: баннеры, концертные туры, афиша с фильтрами (категория, дата, страна) и поиском.
  Два вида афиши: «Афиши» (одна карточка на шоу, даже если оно идёт в нескольких городах) и «По датам» (список по дням).
- `#/e/<slug>` — событие: большой баннер, факты (когда / где / возраст), даты и билеты, описание, площадка на карте, «В календарь» (.ics), другие города
- `#/t/<slug>` — тур: все даты по городам
- `#/s/<название>` — то же для шоу, которое идёт в нескольких городах, но не оформлено как тур (например, Sade)

### Демо-покупка
Кнопки «Osta pilet / Купить» (на странице события и во всплывающей плашке карточки) открывают демо-оформление прямо на новом сайте:
1. **Места** — схема зала с тремя ценовыми зонами, до 8 мест, места держатся 10 минут.
2. **Данные** — имя, e-mail, телефон, согласие с правилами (с проверкой полей).
3. **Оплата** — выбор способа (банки, карта, Apple/Google Pay), имитация обработки.
4. **Готово** — номер заказа и электронные билеты с QR-кодом, «В календарь».

Это только демо: деньги не списываются, данные никуда не отправляются, схема зала сгенерирована.
Ссылка «Osta päris pilet ↗» внизу окна ведёт на настоящую покупку на текущем сайте.

## Обновить данные

```bash
python3 tools/scrape.py /tmp/tb.json && python3 tools/build_data.py /tmp/tb.json assets/data.js
```

## Перенос на бэкенд

Текущий сайт работает на Rails (серверные шаблоны). Дизайн переносится так:
1. `styles.css` подключается как есть, а разметка из функций `cardHTML`, `renderEvent`, `renderTour` в `app.js` переносится в шаблоны (view).
2. `data.js` заменяется данными из базы, например JSON-эндпоинтом `/api/events`.
3. Демо-оформление (`openCheckout` в `app.js`) подключается к реальным данным: схема зала и занятые места из API билетной системы, бронь мест и оплата через платёжного провайдера. Либо, как промежуточный шаг, кнопки покупки вызывают существующий виджет (`js-unifd-trigger-link` с `data-unifd-showtime` и `data-unifd-title`).
